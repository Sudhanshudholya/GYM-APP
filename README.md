## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Sudhanshudholya/GYM-APP
```

Go to the project folder:

```bash
cd project-folder
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The project will run on:

```text
http://localhost:5173
```
